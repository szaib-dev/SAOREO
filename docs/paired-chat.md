# Paired Together messaging

A secure pairing has one persistent local conversation. The main chat, call chat and shared-watch Chat tab use that conversation. One-time rooms still have their own temporary room chat. WebRTC calls, screen sharing, streaming and playback synchronization retain their existing lifecycle.

Paired messages and attachment chunks use compact A256GCM JWE through Nimbus JOSE+JWT. Android Keystore uses the existing pairing secret to derive separate message and attachment keys. Only the paired devices hold the secret. The server sees authentication, timing, routing and delivery metadata. This pairing model has no forward secrecy. Local history is in app-private storage. Completed attachments are stored as encrypted chunks. Opening them creates a removable app-private preview, and gallery export and Android sharing require a user action. Histories containing older plaintext attachment copies migrate the file when opened.

The SQLite migration adds a stable conversation ID for existing pairs and preserves their credentials. The server acknowledges a message only after its ciphertext is stored. It clears queued ciphertext after durable recipient acknowledgement, retains deduplication and receipts for 14 days, and handles read acknowledgement separately. Attachments resume by chunk, are authenticated per chunk, and are verified against the encrypted descriptor’s SHA-256 before the server copy is acknowledged. Undownloaded attachments expire after seven days. Per-device and global queue limits are configurable through TOGETHER_CHAT_PER_DEVICE, TOGETHER_CHAT_QUEUE_BYTES, TOGETHER_ATTACHMENT_PER_DEVICE_BYTES and TOGETHER_ATTACHMENT_QUEUE_BYTES.

The server records ring outcomes. It reports Ringing to the caller only after the recipient’s alert is acknowledged. Android records media connection and duration from WebRTC. A lost server process cannot replay a stale ring. Message and missed-call push wakes carry no message text. Android renders the private notification with a generic public version. Reply, mark as read and mute actions are handled locally.

Themes, wallpaper, and partner photos are device-local. Storage settings cover encrypted media usage, clearing previews and media auto-download. Password-protected backups use Tink Streaming AEAD with a salted PBKDF2-HMAC-SHA256 key. They include the current conversation, call history, and locally available attachments. Restore verifies the encrypted stream and merges history into the selected pairing without resending messages. Backups contain no device pairing credentials.

Run the server suite with `python -m unittest discover -s server/together`. Build the ARM64 APK and Android artifacts with `gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest -PsaoreoAbi=arm64-v8a`. Build with the default ABI selection to run on the x86-64 emulator. Verify locked-screen notifications, Do Not Disturb, voice recording, network handoffs, camera switches and Smart Clarity on two physical phones before relying on the rollout for daily use.
