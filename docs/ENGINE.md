# Engine, network and distribution

The application uses youtubedl-android 0.18.1 as its Android launcher for CPython, QuickJS and FFmpeg. Its published package contains ARM64 and x86-64 native libraries and installs Android-compatible runtime files into app-private storage. Its default yt-dlp payload is 2025.11.12. SAOREO supplies the official 2026.10.26 Unix zipimport asset instead and verifies the pinned SHA-256 before launching it. That ZIP includes yt-dlp-ejs 0.8.0. The Android wrapper supplies CPython 3.12, which satisfies the engine's Python 3.11 minimum. The wrapper supplies the path to QuickJS through `--js-runtimes`. Restarting the app reuses the installed engine, and requests never use a shell or an auto-updater.

The engine decision considered invoking a host Python runtime and provisioning separate Node or Deno binaries. These would introduce their own Android binaries, ABI packaging and startup work. The selected packaged QuickJS path is smaller and directly supported by the wrapper. The Stock wrapper does not ship a configured curl_cffi or browser-impersonation target. YouTube proof-of-origin requirements, authenticated media, TikTok challenges and platform changes can still make eligible public links fail. The Snapchat Spotlight fallback reads public Open Graph MP4 metadata from the page and only transfers assets served by the declared Snapchat CDN. The direct Pinterest image resolver accepts explicitly declared originals on i.pinimg.com and never synthesizes a path from a thumbnail. The currently implemented multi-image support depends on the page exposing matching original assets.

- Android permissions are limited to networking, notifications and foreground services. The optional floating shortcut additionally requires explicit Android overlay permission.
- Link parsing enforces HTTPS and a supported platform hostname. The native extractor uses a local CONNECT proxy that resolves public addresses, connects to a validated address, and blocks non-HTTPS proxy requests. Direct Pinterest and image-preview traffic uses the same public DNS validation. The proxy blocks private, loopback, link-local and common reserved destinations and restricts CONNECT to port 443. It does not inspect end-to-end TLS.
- HLS uses the Python downloader, with bounded fragment retries. FFmpeg is used for local merges. If a source requires an unhandled downloader, authentication, DRM, or unsupported network protocol, it can fail rather than silently produce a partial file.
- Native components run under the app UID. The Kotlin package boundary and process launcher do not constitute a security sandbox against compromised native code. The CONNECT proxy protects traffic that honors the configured proxy. It is not a kernel-enforced egress boundary. Permissions such as SAF grants are associated with the app UID.
- Temporary transfers use UUID-named app-private directories. Final publication validates media headers/tracks and uses a pending MediaStore entry. This is a structural check, not a full decode of every frame. A hard process kill during publication can leave an Android pending row or an orphaned published item.
- Status saves use SHA-256 to detect duplicate copies in the download history. Clearing history also removes the association used for duplicate detection.
- Background jobs use WorkManager and its foreground-service support. Android can restrict background starts or long-running workers depending on OS version and job quota. Unmetered-only uses Android's metering policy, which can also allow unmetered Ethernet and exclude a metered hotspot. Link preview can still use the current connection.
- Diagnostic timings exclude URLs and use the monotonic clock. Video timing observes the first transfer-file growth. Direct media timing records the first body read.

## Upstream sources and licensing

- [youtubedl-android release 0.18.1](https://github.com/yausername/youtubedl-android/releases/tag/0.18.1), GPL-3.0. The linked version supplies Python, FFmpeg and QuickJS. See the accompanying GPL text and upstream source.
- [yt-dlp release 2026.10.26](https://github.com/yt-dlp/yt-dlp/releases/tag/2026.10.26), Unlicense with additional third-party terms for the released ZIP. The official checksum manifest and its signature are included.
- [yt-dlp-ejs 0.8.0](https://github.com/yt-dlp/ejs), included within the engine ZIP. Review embedded third-party licenses before distribution.
- [CPython](https://www.python.org/downloads/source/) uses the Python Software Foundation license. [QuickJS](https://bellard.org/quickjs/) uses the MIT license. [FFmpeg](https://ffmpeg.org/legal.html) license obligations depend on the bundled native build configuration.
- AndroidX, Coil and OkHttp use Apache 2.0. The CycloneDX inventory captures resolved runtime Maven artifacts and the identified native components. Exact native build flags and corresponding source for FFmpeg and related codecs require verification before public redistribution. The debug APK is intended for device testing.
The small set of Compose extended Material icons is embedded as individual source vectors from AndroidX 1.7.8 under Apache 2.0.

SDK security note. This project excludes platform login, credential handling, browser impersonation, and DRM bypass. Support covers media the user has permission to download.
